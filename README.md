# Eva Stevanovic — Portfolio Site

This React/Vite portfolio site highlights software systems, workflow automation, and intelligent product tooling.

## Local development

```bash
cd portfolio-site
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Use this site as a recruiter-facing portfolio with project summaries and links.
- Update the repository URLs and contact links to your real GitHub and LinkedIn profiles.
- Deploy to GitHub Pages from the `main` branch or the repo's `gh-pages` branch.
